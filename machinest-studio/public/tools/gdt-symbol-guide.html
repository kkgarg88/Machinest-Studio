How to read a feature control frameFeature control frame कैसे पढ़ें

The box on the drawing that holds a GD&T symbol. Read it from left to right.

Read it as: The axis of this hole must lie inside a Ø0.1 mm cylinder at its true position. Bonus tolerance is allowed as the hole grows bigger than its smallest size (MMC). Measure from datum A first, then B, then C.

ऐसे पढ़ें: इस hole का axis, true position पर बने Ø0.1 mm cylinder के अंदर रहना चाहिए। Hole अपने सबसे छोटे size (MMC) से जितना बड़ा होगा, उतना bonus tolerance मिलेगा। पहले datum A, फिर B, फिर C से नापें।

Datum feature

A letter in a box with a triangle on the drawing marks a datum surface, like A. It is the reference you hold or rest the part on while measuring.

Drawing पर triangle के साथ box में letter, जैसे A, datum surface दिखाता है। नापते समय part को इसी reference पर रखते या पकड़ते हैं।

Basic dimension

A dimension inside a box, like 30, is the exact theoretical value with no ± tolerance. The allowed error comes from the feature control frame.

Box के अंदर dimension, जैसे 30, exact theoretical value है, इस पर ± tolerance नहीं होता। Error की limit feature control frame से आती है।
