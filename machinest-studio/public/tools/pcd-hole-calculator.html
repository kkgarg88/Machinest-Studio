How to use this calculator




Angle convention
  • 0° is on the X+ side (3 o'clock). 90° is Y+ (12 o'clock).
  • CCW counts holes anti-clockwise, the same way as Fanuc polar coordinates (G16).
  • CW counts holes clockwise. Use it when the drawing numbers holes clockwise.
  • Negative start angles are fine. For example −30° is the same as 330°.


Full circle vs arc
  • Equal on full circle: holes are spaced 360° ÷ number of holes.
  • Fixed angle (arc): you set the angle between holes. Use it for holes on a part of the circle, like 3 holes at 30° on a flange segment.
  • Need a missing hole in a full pattern? Keep the full count and type its number in Skip holes.


Checking the pattern
  • Hole-to-hole (chord) = PCD × sin(step ÷ 2).
  • Measure over two neighbouring holes and subtract one hole diameter to get the chord.
  • Check the drawing preview: hole 1 is orange and numbering follows your direction.


X/Y list or G16 polar?
  • X/Y points work on every control and are easy to verify on the screen.
  • On Fanuc, G16 polar mode does the same thing with X = radius and Y = angle.
  • Always set the work zero at the PCD centre if you use G16, or shift with a local offset.




Accuracy: These are theoretical positions from the values you enter. Always check the drawing datum, work offset and a dry run before cutting.
